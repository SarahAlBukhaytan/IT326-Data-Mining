# Stress Level

## Project Description

This project aims to analyze mental health and lifestyle data to better understand individuals' stress levels. The project uses different lifestyle and mental health-related attributes, such as sleep hours, exercise level, work hours, screen time, social interaction, and happiness score.

For the classification task, the project aims to classify individuals' stress levels into three categories: Low, Moderate, and High. For the clustering task, the project aims to group individuals with similar lifestyle and mental health characteristics to identify patterns within the dataset.

## Motivation

We chose to analyze stress levels because stress is an important aspect of mental well-being and may be associated with different lifestyle habits. Understanding the patterns related to stress can provide useful insights into how characteristics such as sleep, exercise, work hours, screen time, social interaction, and happiness are related to different stress levels.

The dataset was selected because it contains a variety of lifestyle and mental health-related attributes that are suitable for applying classification and clustering techniques.
